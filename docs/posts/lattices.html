2026-08-01 Bounds for Ordered Sets

The essential idea from the previous post on orders is that comparing the elements of a set gives rise to relations between them and adding a “sense” (a measure that quantifies the relation mathematically) to the relation allows for the ordering of elements within the set. Taking only those ordered sets where elements can be related to themselves (irreflexive) and where not every element is related to another in the set (partial), taking subsets of such posets and checking if any notable properties emerge from them is interesting exercise, so let’s start there.

Subsets of ordered sets #

Take a subset YYY of an partially ordered set XXX with relation RRR on it. In XXX :

  • a lower bound is an element xxx where xRy,∀y∈Yx R y, \forall y \in YxRy,∀y∈Y (x bounds Y from below)
  • an upper bound is an element xxx where yRx,∀y∈Yy R x, \forall y \in YyRx,∀y∈Y (x bounds Y from above)

The set of all lower bounds is defined as:

Yℓ={x∈X∣(∀y∈Y) xRy}Y^{\ell} = \{ x \in X \mid (\forall y \in Y)\ x R y \}Yℓ={x∈X∣(∀y∈Y) xRy} (the set of all values in X that bound the subset Y from below)

and the set of all upper bounds as:

Yu={x∈X∣(∀y∈Y)yRx}Y^u = \{x \in X | (\forall y \in Y) y R x \}Yu={x∈X∣(∀y∈Y)yRx}

(the set of all values in X that bound the subset Y from above)

Note that all of these arises from nothing more than taking a subset of the original partially set and using the relation RRR to relate members of the original set XXX and the subsets YYY . Because XXX is an ordered set using a binary relation RRR , the sets of bounds are also ordered in two directions - lower and upper.

When the set of upper bounds Yu^uu has a least element, it is the least upper bound of YYY which is given by xxx :

(∀x′∈X[((∀y∈Y)yRx′  ⟺  xRx′)])(\forall x' \in X [((\forall y \in Y) y R x' \iff x R x')])(∀x′∈X[((∀y∈Y)yRx′⟺xRx′)])

Considering the dual, the set of lower bounds Yl^ll has a greatest element or the greatest lower bound and is given by xxx :

(∀x′∈X[((∀y∈Y)x′Ry  ⟺  x′Rx)])(\forall x' \in X [((\forall y \in Y) x' R y \iff x' R x)])(∀x′∈X[((∀y∈Y)x′Ry⟺x′Rx)])

In literature, the least upper bound is the supremum (written as sup YYY ) of the subset YYY and the greatest lower bound is the infimum of Y
(written as inf YYY )

Important points to note are:

  • A set Y need not have a supremum or an infimum.

    • E.g. Let X = {a, b, c, d} be a poset with:

    y relation x

    S^u = {c, d}

    To get only one element out of SuS^uSu requires a comparision between c and d but since R does not hold for both, there’s no least element or supremum in {c, d}.

  • A supremum or an infimum, if either exist, are always unique. Looking at the definition above, if x and x’ are both upper bounds in XXX , then we must have xRx′x R x'xRx′ and x′Rxx' R xx′Rx which is only possible when x’ = x in a poset (the antisymmetry property).

  • The supremum or the infimum of a set may or may not belong to the set itself.

    • The closed interval [0, 1] of reals has a sup of 1 which is contained in the set itself.
    • The open interval (0, 1) of reals again has a sup of 1 but this is not contained within the set {0,1}.

An poset X has a bottom element if there exists ⊥∈X\bot \in X⊥∈X (called bottom) with the property that ⊥Rx\bot R x⊥Rx for all x ∈X\in X∈X . Lattices #

So far, the definitions of subsets of posets have meant any subset of a poset XXX . Now if the definition were to narrowed down to every two-element (or doubleton) subset of XXX , then a structure called a lattice emerges from XXX only if:

  • ∀x,y∈X\forall x, y \in X∀x,y∈X , the least upper bound exists. This is called a join and denoted by x∨yx \vee yx∨y
  • ∀x,y∈X\forall x, y \in X∀x,y∈X , the greatest upper bound exists. This is called a meet and denoted by x∧yx \wedge yx∧y

A poset XXX is a join-semilattice (or upper-semilattice) in which ∀x,y∈X\forall x, y \in X∀x,y∈X , x∨yx \vee yx∨y exists. The dual holds for meet-s semilattices (lower-semilattices) i.e. ∀x,y∈X\forall x, y \in X∀x,y∈X , x∧yx \wedge yx∧y .

For a subsets S⊆XS \subseteq XS⊆X :

  • ⋁S\bigvee S⋁S is the least upper bound or join of subset SSS
  • ⋀S\bigwedge S⋀S is the greatest lower bound or meet of subset SSS

If both ⋁S\bigvee S⋁S , ⋀S\bigwedge S⋀S exist for all S⊆XS \subseteq XS⊆X , the XXX is a complete lattice.

Filters #

A principal filter or principal up-set on a poset XXX generated by an element yyy is defined as:

↑y={z∈X∣yRz}\uparrow y = \{ z \in X | y R z \}↑y={z∈X∣yRz}

↑y\uparrow y↑y is everything in the poset that is “at” or “above” y (at because y R y by definition).

The set of upper bounds of two element set, {x,y}uisgivenby\{x, y\}^{u} is given by{x,y}uisgivenby y$ since x R y, nothing “below” YYY can be an upper bound. Since the least element of ↑y\uparrow y↑y is y, x∨y=yx \vee y = yx∨y=y .

A principal down-set on a poset XXX generated by an element zzz is defined as:

↓x={z∈X∣xRz}\downarrow x = \{ z \in X | x R z \}↓x={z∈X∣xRz}

↓x\downarrow x↓x is everything in the poset that is “at” or “below” x (at because again x R x by definition).

The set of lower bounds of two element set, {x,y}l\{x, y\}^{l}{x,y}l is given by ↓x\downarrow x↓x as nothing “below” x can be a lower bound. Since the least element of $x is x, x∧x=xx \wedge x = xx∧x=x .

Hasse diagrams #

This far, diagrams for definitions have shown abstract versions of posets, their subsets, upper/lower bounds. One representation of specific posets are Hasse diagrams. A Hasse diagram for a poset XXX with x,y∈Xx, y \in Xx,y∈X is done as follows:

  1. Each x∈Xx \in Xx∈X is represented by a small circle.
  2. For each pair x ⋖\lessdot⋖ y (y covers x i.e. y immediately succeeds x when ordered using RRR ), a line from x to y is drawn
    1. and 2. must adhere to the following:
    • when x RRR y, the circle depicting x is lower than the one
      depicting y
    • the lines joining circles may cross each other but the circles depicting elements much never intersect lines.

This Hasse diagram is a representation of poset X={(a,d),(b,e),(b,d),(b,f),(c,f),(c,g),(d,h),(e,h),(e,i),(f,i),(g,i)}X = \{(a, d), (b, e), (b, d), (b, f), (c, f), (c, g), (d, h), (e, h), (e, i), (f, i), (g, i)\}X={(a,d),(b,e),(b,d),(b,f),(c,f),(c,g),(d,h),(e,h),(e,i),(f,i),(g,i)}

Moving upward from an circle depicting an element shows the transitive relations e.g. b R e R h   ⟹  \implies⟹ b R h. Elements e and d are not ordered by RRR (d∣∣ed \hspace{0.2em}|| \hspace{0.2em} ed∣∣e ). The reflexivity of elements is implied.

Lattices as an Algebraic Structure #

A mathematical or a computational entity has an algebraic structure when it is comprised of:

  • a set of elements
  • a finite collection of operations on its elements
  • and a finite set of identities (axioms) which hold for all possible elements of the structure.

Sets themselves have identities that any set must follow. As ordered sets with other features, lattices are algebraic structures too,a denoted by ⟨L;∨,∧⟩⟨L; \vee, \wedge⟩⟨L;∨,∧⟩

The following rules are equivalent for all lattices from poset XXX , where x,y∈Xx, y\in Xx,y∈X :

  1. x R y
  2. x ∨\vee∨ y = y
  3. x ∧\wedge∧ y = x

and give rise to the following axioms with x,y,z∈Xx, y, z \in Xx,y,z∈X :

  • (x ∨\vee∨ y) ∨\vee∨ z = x ∨\vee∨ (y ∨\vee∨ z) (associative)
  • x ∨\vee∨ y = y ∧\wedge∧ x (commutative)
  • x ∨\vee∨ x = x (idempotency)
  • x ∨\vee∨ (x ∧\wedge∧ y)= x (absorption)

The four axioms hold for their dual versions where ∨\vee∨ and ∧\wedge∧ are exchanged.
